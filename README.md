# 🏷️ INSTiGEN — Inventory Sticker Generator

**INSTiGEN** is a simple and efficient **Inventory Sticker Generator** designed to help users generate printable inventory stickers from **Excel files to PDF** with just a few clicks.

This project was designed in **Figma** and developed using **HTML, CSS, and JavaScript**, focusing on ease of use, flexibility, and fast processing — perfect for small businesses, warehouses, offices, and inventory managers.

🚀 **Live Website**  
👉 https://instigen.netlify.app/

🎨 **Figma Design**

## 📌 About the Project

INSTiGEN allows users to **generate inventory stickers directly from Excel data** and export them into **PDF format** without complex setup or software installations.

Users can:
- Customize Excel headers
- Upload their Excel file
- Automatically generate inventory stickers
- Download the stickers as a printable PDF

This project demonstrates a **UI-to-code workflow**, client-side file handling, and dynamic data rendering using Vanilla JavaScript.


## 🚀 Core Features

✔ Generate inventory stickers from Excel files  

✔ Customizable Excel headers  

✔ Downloadable Excel template  

✔ Export generated stickers to PDF  

✔ Clean and user-friendly interface  

✔ Fast and lightweight static website  

✔ No backend required  


## 🧩 Technologies Used

- **Figma** – UI/UX design  
- **HTML5** – Structure  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – File parsing, data handling, and PDF generation  
- **SheetJS** - For Excel reading & writing  
- **jsPDF** - For generating PDF files  
- **HTML2Canvas** - For creating snapshot of stickers to PDF  
- **Git & GitHUb** - For version control  
- **Netlify** – Hosting and deployment  


## 📄 How It Works

**Step 1.** Customize the headers based on your inventory needs  

**Step 2.** Download the Excel template provided on the website  

**Step 3.** Fill in your inventory data in Excel  

**Step 4.** Upload the Excel file to the website  

**Step 5.** Generate and download your inventory stickers as a PDF  

And it is now ready to be printed!
